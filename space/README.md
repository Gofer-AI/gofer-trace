# Gofer Trace

Multimodal workflow memory for AI agents.

Gofer Trace lets users upload or record a workflow video, send it to an AMD MI300X backend for multimodal analysis, view segmented workflow context, chat with an agent over the generated trace, and export reusable agent memory.

## Demo Flow

1. Upload or record a workflow video.
2. Analyze the workflow through the AMD MI300X backend.
3. View a segmented timeline and contextual video launcher.
4. Chat with the agent over the workflow trace.
5. Export Agent Memory JSON or Segment Launcher HTML.
